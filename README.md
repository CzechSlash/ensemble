# Ensemble

Ensemble is a fork of [Encore](https://github.com/ScoreSaber/encore) by ScoreSaber, built for running Beat Saber across many headsets and PCs at tournaments and events.

It stays compatible with stock Encore. Run Ensemble on one control PC, and keep Encore on your station PCs and the Encore companion on your Quest headsets.
